
# Enhanced python Calculator Command-Line Application

## Project Overview

This project is an advanced Python calculator developed
using Object-Oriented Programming (OOP) and design patterns.

## Planned Features

- Basic and advanced arithmetic operations
- Interactive command-line interface (REPL)
- Factory Design Pattern
- Memento Design Pattern for undo and redo
- Observer Design Pattern for logging and auto-save
- Calculation history using pandas
- CSV save and load functionality
- Input validation and error handling
- Unit testing using pytest
- GitHub Actions for CI/CD

## Optional Features

- Color-coded terminal outputs
- Dynamic help menu using Decorator Pattern
- Command Design Pattern

## Installation

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies:

   python -m pip install -r requirements.txt
